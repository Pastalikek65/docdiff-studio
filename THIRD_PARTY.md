# Third-party components

Authored DocDiff Studio source and synthetic fixtures use Apache-2.0. Dependencies retain their own licenses. `third_party/dependencies.json` inventories the pinned source dependency graph and distinguishes browser bundle candidates, development dependencies and optional platform packages. JavaScript libraries are installed at build time; the desktop runs compiled browser bundles and Electron's built-in Node APIs, without an application node_modules tree. `scripts/distribution-notices.mjs` copies browser bundle candidates' license texts into `third_party/npm/` before packaging.

The rendered application includes PDF.js (Apache-2.0), React/React DOM/Scheduler (MIT) and jsdiff (BSD-3-Clause). The DOCX implementation dependencies, when used, are fflate and fast-xml-parser and their MIT dependencies. The desktop distribution includes Electron under MIT and Chromium and other components with their upstream notices: retain `LICENSE.electron.txt` and `LICENSES.chromium.html` from the Electron distribution. Native canvas packages in the source graph are PDF.js optional Node dependencies; the comparison worker uses browser OffscreenCanvas. They are not redistributed as application Node modules.

PDF.js assets keep their original license files under `dist/vendor/pdfjs/`: CMaps, Foxit/PDFium fonts, Liberation fonts, ICC data and JPEG2000/JBIG2/QCMS components. These do not all use the PDF.js root Apache license. Do not remove their notices when self-hosting or repackaging.

The unmodified Liberation Sans fonts distributed by PDF.js 6.4.299 are version 1.07.4, under GPLv2 with the Liberation font exception, **not** the license used by later Liberation versions. Their complete corresponding source (SFD files, Makefile and build scripts) is included in `third_party/sources/liberation-fonts-1.07.4.tar.gz`, SHA-256 `ad98b7498dc2992f7f0868f79b65ce4a720a3acdb63ab3f1f1cb6881117a5406`. Build instructions are inside that archive. Source obtained unchanged from [Debian's upstream source archive](https://deb.debian.org/debian/pool/main/f/fonts-liberation/fonts-liberation_1.07.4.orig.tar.gz), matching its published source-package checksum. [PDF.js upstream font documentation](https://github.com/mozilla/pdf.js/blob/v6.4.299/external/standard_fonts/README.md) identifies the exact font version and exception. No font was modified.

`pdf-lib` is an MIT development-time fixture generator. Corpus documents contain only independently authored fictional content. Browser tests use Playwright; these tools are not a hosted service and no document is uploaded.

Development v1 adds local OCR through Tesseract.js 7.0.0 and its matching core 7.0.0. The wrapper and core project use Apache-2.0; their compiled libraries have separate licenses. `third_party/ocr/provenance.json` binds unchanged upstream notices and build provenance for Leptonica, libjpeg, giflib, libpng, libtiff, libwebp, zlib, Tesseract, OpenLibm and Emscripten 4.0.15/runtime components. OpenLibm's notice distinguishes the library's permissive licenses from LGPL test files; the preserved upstream build targets the static library, not those tests. The complete libjpeg README is retained and contains the Independent JPEG Group acknowledgment and terms.

The English model is unchanged `tessdata_fast/eng.traineddata` at commit `87416418657359cb625c412a48b6e1d6d41c29bd`, Apache-2.0, SHA-256 `7d4322bd2a7749724879683fc3912cb542f19906c83bcc1a52132556427170b2`. No model is downloaded during use. `scripts/vendor-assets.mjs` verifies source notices/model hashes and generates a local asset inventory, retaining the upstream worker's license file. `third_party/ocr/worker-dependencies.json` separately inventories the upstream prebuilt worker's nine embedded JavaScript dependencies, including Buffer and ieee754, with integrity-checked registry license texts and per-source-map correspondence. Those embedded versions can differ from this project's source dependency graph. Preserve the entire `third_party/ocr/` directory when repackaging.

The initial full development dependency audit reports a moderate denial-of-service advisory in `sprintf-js` used through Electron packaging/downloading tools. No patched version is published in its 1.x line; this is recorded instead of force-changing the toolchain. It is absent from the product dependency audit. The exact release verification must record the current audit results and whether the built archive contains that package; source audit and bundled application contents are separate scopes.
