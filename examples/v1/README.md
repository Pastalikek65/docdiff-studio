# v1 synthetic corpus

This directory holds a separate, reproducible corpus for v1 DOCX and offline OCR work. It does not replace or regenerate `examples/corpus`, which remains the published PDF MVP corpus.

Run `node examples/v1/generate.mjs` from the repository root. The script writes deterministic DOCX, PDF, and raster fixtures under `examples/v1/corpus/` and refreshes `manifest.json` with every fixture's byte size and SHA-256. Source text, OOXML, raster scans, and PDFs are generated locally by this script. There are no third-party source documents or example PDFs.

DOCX pairs cover main-body paragraphs, table cells, insertions/removals, unique moves, duplicate move ambiguity, split runs, and tabs. A deterministic medium DOCX pair contains 1,000 paragraphs and 500 simple table rows with one changed paragraph number and one changed cell. Searchable PDF pairs cover one unique page reorder and reordered duplicate pages that must remain ambiguous. Separate malformed packages probe traversal/absolute/encoded paths, CRC, declared per-part and aggregate inflation sizes, DTD/entity declarations, XML depth, and entry count. Header, tracked-revision, unknown text-bearing element, and alternate namespace-prefix fixtures exercise unsupported or noncanonical OOXML behavior; a comparison must fail, become incomplete/uncertain, or show a change rather than report identical when the pair differs. A synthetic hostile-looking paragraph and hostile file name exercise standalone HTML and JSON report escaping and source-data omission.

The OCR PDFs use synthetic grayscale PNG page images rendered locally with the repository-bundled Liberation Sans font through the pinned Playwright Chromium runtime. The corresponding PNGs are included as raster references. Scan-only pages contain no PDF text objects or hidden text layer. They cover word and number differences, identical scans (which must remain uncertain when OCR evidence is used), a mixed selectable-text/scanned document with selected-page OCR, and a twelve-page cancellation workload. OCR output is local and generated at test time; the trained data is not copied into these fixtures.

All corpus content is synthetic and covered by the repository's Apache-2.0 license. The raster text uses Liberation Sans, whose license and source attribution are already tracked in the repository's third-party notices. Do not treat it as representative of every DOCX producer, scan quality, font, language, or hostile-file construction.
