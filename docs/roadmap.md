# Roadmap

The [PDF MVP preview](https://github.com/Pastalikek65/docdiff-studio/releases/tag/v0.1.0) is published after successful actual source and extracted-package comparison/export flows on Windows and Linux. Stable v1 remains in development.

Before stable v1: safe DOCX paragraph and basic table-cell comparison; moved text blocks; selected-page local OCR with visible confidence and uncertain results; saved comparison options; batch comparison and JSON through the same engine; keyboard/long-job behavior; measured representative synthetic datasets; independently reviewed Windows/Linux packages and release evidence.

Later possibilities: richer PDF table structure, more OCR languages and alignment-review controls. These are ideas, not promises or implemented features. Legal interpretation, cloud accounts, paid processing and complete complex-table reconstruction are outside the current contract.
