# Roadmap

The [PDF MVP](https://github.com/Pastalikek65/docdiff-studio/releases/tag/v0.1.0) and [feature beta](https://github.com/Pastalikek65/docdiff-studio/releases/tag/v0.2.0) are published with successful source and extracted-package flows on Windows and Linux. The beta adds bounded DOCX paragraph/basic-cell comparison, exact unique-text moves, selected-page local English OCR with visible uncertainty, sequential batches, JSON reports, keyboard navigation and cancellation. Its exact Windows package also passed on Windows 11.

Stable v1 requires fresh exact-version package tests on both platforms, profile/report compatibility from the old PDF preview, and independent final review. The support contract and release verification record define the qualified scope; a feature beta is not stable-v1 evidence by itself.

Later possibilities: richer PDF table structure, more OCR languages, saved comparison presets and alignment-review controls. These are ideas, not promises or implemented features. Legal interpretation, cloud accounts, paid processing and complete complex-table reconstruction are outside the current contract.
