# Roadmap

The published [stable v1.0.0 release](https://github.com/Pastalikek65/docdiff-studio/releases/tag/v1.0.0) includes PDF and supported DOCX comparison, exact unique-text moves, selected-page local English OCR with visible uncertainty, sequential batches, versioned JSON reports, keyboard navigation and cancellation. Its exact packages passed source and extracted-package acceptance on Windows and Linux; the Windows package also passed on Windows 11. The earlier [0.1.0 PDF MVP](https://github.com/Pastalikek65/docdiff-studio/releases/tag/v0.1.0) and [0.2.0 feature beta](https://github.com/Pastalikek65/docdiff-studio/releases/tag/v0.2.0) remain published previews.

The stable v1.0.0 gate is complete. Its evidence includes exact package hashes, 23-step desktop flows, nine-step portable upgrade tests using a synthetic profile marker and report compatibility, and an independent final publication review. See [verification](verification.md) for the precise scope and limitations. The profile marker demonstrates directory reuse; it does not establish migration of arbitrary user data.

Later possibilities: richer PDF table structure, more OCR languages, saved comparison presets and alignment-review controls. These are ideas, not promises or implemented features. Legal interpretation, cloud accounts, paid processing and complete complex-table reconstruction are outside the current contract.
